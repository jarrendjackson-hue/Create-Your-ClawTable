# Example: what `dist/clawtable-bundle.md` looks like

This is a **trimmed sample** so you can see the shape of the final bundle before you build one. Your real bundle will be much longer — full orchestrator prompt + every seat — and is generated by:

```bash
python clawtable.py build
```

What lands in `dist/clawtable-bundle.md`:

```text
# ClawTable Session Bundle

Paste this entire file into Claude, ChatGPT, or any LLM with a long context
window. The orchestrator prompt comes first, then each loaded seat. Tell it
your idea after.

---

# ClawTable Orchestrator
... (full orchestrator prompt) ...

---

## Loaded seats (3)

---
# Alex Hormozi Advisor Seat
... (seat file) ...

---
# Charlie Munger Advisor Seat
... (seat file) ...

---
# MFM Advisor Seat
... (seat file) ...

---

## Your turn

Tell the orchestrator your idea or goal. It will run the rounds.
```

You paste the whole thing into a fresh Claude/ChatGPT chat and follow with your question. The orchestrator runs context framing → independent proposals → cross-examination → revision → vote → synthesis.
